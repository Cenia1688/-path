## 腾讯云更新

在原服务目录之外解压本包，先试运行并备份原服务目录。不要把旧版私密部署包或环境文件放进GitHub仓库。

### 直接运行

需要 Node.js 22.10+，推荐24：

```sh
HOST=127.0.0.1 PORT=3000 node server.mjs
```

让原有反向代理指向此端口。服务器进程需要通过原来的进程管理服务保持运行。

### Docker

本版不需要 `.env` 文件：

```sh
docker compose up -d --build
```

默认只映射服务器本机 `127.0.0.1:3000`，可沿用原反向代理。若部署方式是直接对公网开放端口，请按现有服务器网络配置设置 `BIND_ADDRESS` 与 `PUBLIC_PORT`，并同步检查防火墙。
