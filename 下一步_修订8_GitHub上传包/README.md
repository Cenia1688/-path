# 下一步 · 修订8

面向思想政治教育、哲学、社会学学生的路径探索原型，目前以思想政治教育为试点。页面沿用手写标题、纸张背景和拼贴插图。

本版流程：封面 → 四个主枝 → 逐层分类 → 具体路径介绍框架 → 自愿填写五道问题。填写页同时展示共用及分组评价标准。路径事实尚未采集完成，空白项标记待核实，不生成匹配率。

## 启动

需要 Node.js 22.10 或更新版本，建议使用 Node.js 24。没有外部依赖，不需要安装依赖。

```sh
node server.mjs
```

打开 http://localhost:3000 。Mac 也可双击“启动网站.command”，默认使用3001端口。

## 本版数据与分析

- 没有 DeepSeek 密钥、模型调用代码或在线分析接口；无需配置API。
- 五题回答和旧记录保存在本设备浏览器，可导出备份。服务端不接收问卷。
- 旧版填写与已保存结果可回看；本版只做本地规则对照。
- 目录中保留380个旧节点，包含岗位、进入渠道、内部角色和深造方向，并非380种已核实职业。
- 包内不含私人环境文件、源工作簿、设计原稿或旧部署包。

## 检查与部署

```sh
npm test
npm run check
docker compose up -d --build
```

默认Docker仅向本机3000端口提供服务，供服务器上的反向代理访问。详见 `deploy/修订8说明.md`。GitHub仓库保存代码，与网站访问地址分别管理。

发布包可以用 `python3 scripts/package-public.py` 重建，包含文件哈希清单。项目介绍见 `docs/项目介绍与计划书准备.md`，另有单独交付的Word版。
