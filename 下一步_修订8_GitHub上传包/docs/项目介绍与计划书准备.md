# 下一步项目介绍与计划书准备

面向新加入的项目成员与计划书讨论　2026年11月6日

## 我们在做什么

我们希望为东北师范大学马克思主义学部思想政治教育、哲学、社会学三个专业学生提供路径探索工具。当前先以思想政治教育专业为试点：把可能的道路整理清楚，把实际工作和进入条件说明白，再帮助用户看见自己的期待与现实条件之间的取舍。

现在的主要交付是一套路径目录、分组评价模型和响应式网站原型。网站已经能呈现逐层选择的流程，但大部分具体院校和岗位的资料尚未采集完成。模型字段和软件功能的完成，不等于职业信息库已建成，也不等于模型有效性已获验证。

## 为什么需要这个项目

学生可能只知道“教师、公务员、企业”等标签，不清楚职业内部的任务和不同进入方式。例如高中思政教师可能还承担班级管理、教研、团委或教务工作；同样叫保研，也要区分本校推荐资格与目标院校接收。我们先把这些差异展开，再讨论选择。

## 当前范围与基本原则

职业搜索扩到文科范围，暂不纳入转码等理工路线。目录采用学术研究与深造、在编及公共部门、不在编校企及社会组织、灵活就业与自主经营四个主枝。它是浏览框架，不是互斥的官方职业分类。

上一版有380个混合类型节点和54组分支，里面包括职业岗位、进入渠道、培养计划、内部角色和深造方向，不能称为380种已经核实的独立职业。资料不足时显示未知，不用职业标签替用户决定。

# 模型怎样组织

## 目录层决定从哪里找路

主枝 → 中间分类 → 原分支 → 具体职业或升学入口。每层单独展示，用户不用在一页里看完所有道路。职业与内部兼任角色分开标注；同一实际路径跨视图展示时复用同一标识。

读研入口分为推免与考试招生。推免先核本校推荐资格，再分本校接收与外校接收；考研区分本校、外校、本专业或跨学科，分别保留初试、复试、录取等阶段。跨学科是叠加要求，不把所有学校和学位属性都复制成新树枝。

## 评价层描述道路本身

共用核心有五个：经济回报或阶段投入、地区与迁移要求、时间节奏与生活安排、保障发展与自主空间、具体任务与活动内容。在此之上，推免资格、内保、外保、考研、跨学科，以及教学、行政党群、企业经营等分别使用专属模板，目前共13套。

客观门槛另建规则层。学历、专业、证书、经历等必须对照具体公告核验；用户的期待、不可妥协底线和喜欢的活动另存，不能互相替代。高薪不能抵消必需资格缺口，兴趣也不能证明具备工作能力。

## 理论和产品如何连接

前期理论关注人、现实条件、经历与认知更新。研究编码表区分价值目的、实际资源、制度机会、现实约束、客观门槛、个人底线、兴趣、行动与实际结果。产品首次填写只取必要部分，后续再逐步记录经历与认识变化，不要求五题测完全部研究变量。

霍兰德RIASEC六类兴趣活动维度用于辅助描述具体任务，允许一个任务有多个标签。视觉创作、资料录入、教材研究不能只因都使用PPT就归为同一种活动。职业环境和活动分类已有相关研究；我们的工作重点是本土岗位任务细拆与可查证呈现，仍需验证。

# 用户流程与网站运转

## 用户看到的流程

封面 → 四张主枝卡片 → 中间分类 → 具体道路 → 职业介绍 → 询问是否愿意对照 → 同意后进入个人信息页。点击一张卡片进入下一层，返回键和路径位置支持回看；不同意填写仍可浏览。

## 五道题采集什么

第一题问希望就读或工作的地区。第二题问期待的起步月收入，读研时替换为年度可承担净支出。第三题问每周希望投入的时间上限。第四题对安全稳定、自主独立、成长发展、家庭责任、社会贡献、物质报酬、兴趣与工作内容相符七项作完整排序。第五题选择该组最愿意做的具体活动。

五题均允许暂未确定。价值排序若作答，应排满七项；活动最多选两项。填写页同时展示共用标准、本组专属标准和待核实门槛。缺少成绩、资格等资料时保留未知，不能靠五题推导完整的进入可能性。

## 目前软件实际做到了哪里

本次按手绘流程接入了分层卡片导航、路径介绍框架、自愿填写入口、五题保存和分组标准展示。回答保存在本设备，支持导出；既有记录与结果仍保留。新版流程暂不接入DeepSeek，不调用模型生成匹配结论。现有职业介绍大多是资料框架，并非完整工作画像。

## 后续完整运行方式

经核验的路径资料与用户期待进入规则对照：先查必需门槛，再查用户明示底线，再解释价值取舍与实际任务，最后列出待核实事项和下一步。AI未来可负责解释已有依据和组织文字，不能补造薪资、岗位要求、保研概率或任务占比。恢复接入前应先确定数据范围、发送同意、错误回退和输出校验。

# 怎样实现与验证

## 数据工作流

先选一个边界明确的路径样本，确定字段，再搜集官方公告、学校规则、用人单位资料与访谈。每条事实保存来源、适用年份、对象范围、单位、采集日期和核验状态。自动采集只能辅助取得资料，不能代替专业归类与事实核对。

清洗时处理重复岗位、职业别名、学科代码、税前税后、年月口径、常态与旺季工时等差异。明确否、未知、未回答和不适用分开记录。历史推免比例要保留分子、分母与群体，学长姐个案不能当成录取概率。

## 访谈与任务编码

向在读或从业者询问最近实际完成的任务、频率、评价方式、进入过程与意外之处；把个人经历与整个职业的结论分开。先由两位成员试编码同一段任务，再讨论分歧，修订任务标签和问法。单一访谈不能代表全部学校、地区或单位。

## 预期效果怎样检验

预期帮助学生扩大可见的道路，理解具体工作，识别资格与成本缺口，并提出可执行的查证或探索步骤。检验可以先看：是否能找到目标路径、是否能区分门槛与偏好、是否理解未知信息、是否能在使用后提出下一步行动。

需要记录试用任务完成情况、停顿与误点、五题填写负担、结果理解和后续反馈。可比较使用前后对某条路径的事实认识，但没有合适设计与数据时，不声称网站提高就业率、消除焦虑或准确预测录取。

## 近期样本与分工

答辩前先完善三个有差异的路径样本。可讨论用外保、学校岗位及兼任工作、灵活就业作为候选，最终由团队和导师确认。理论与问法、资料与访谈、数据结构与核验、网站与测试可分线协作，每条事实有采集人和复核人。

# 新成员如何加入与计划书怎样展开

## 新成员的第一轮工作

先用网站走通一遍从封面到五题填写的过程，并阅读全景模型。随后选一个小分支作为练习：画清它与职业、入口、内部职责的关系；列出3至5项关键门槛和若干实际任务；暂时没有证据的部分标记待核实。

和一位已有成员共同核对一条事实记录，理解来源、年份、范围和单位的要求。再完成一段访谈材料的任务编码并互相复核。第一轮交付以结构、证据和问题清单为主，避免一开始独自承担整片职业资料库。具体负责哪一条线由团队协商。

## 计划书建议的章节

一是问题与对象：哪些学生在何种选择情境下缺少什么信息。二是已有研究与理论：概念如何连接、哪些关系仍需检验。三是项目目标：近期样本原型与后续职业信息库分别写。四是研究与实现：访谈、资料采集、编码、规则、网站与试用如何衔接。

五是创新与价值：细拆实际任务、区分门槛与偏好、把信息未知与后续探索连起来；避免把现有兴趣理论或一般网站功能说成原创理论。六是进度与组织：按可验收成果列阶段与责任。七是评估与边界：效果指标、资料质量、用户同意、限制与失败回退。八是资源和预算：按实际活动与依据编制，不先虚构金额。

## 写作前需要团队确认

确认三个展示样本、访谈对象与资料使用范围、每阶段负责人、导师对理论与创新的表述意见，以及现阶段是研究原型还是准备商业验证。需求、产品效果、付费意愿是不同问题，尚无证据时分别写为待验证。
