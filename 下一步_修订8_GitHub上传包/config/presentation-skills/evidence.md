# 从输入到建议的证据链
每个判断区分：本人填写的想法、做过的具体任务和产物、别人给出的反馈、已有资料、尚待核实的设想。会软件、做过任务、拿到机会、喜欢这份工作是不同的信息。
对照岗位时写清“要求什么 → 你已有哪项经历或作品 → 哪一项还不能确定 → 下一步怎样确认”。有作品就先整理与任务相关的部分；仅有“沟通能力强”等自评时，询问具体情境，不自动认定能力不足。别为了申请让用户先学完所有工具。
用户认可的分析步骤：这个人真正影响决定的信息是什么；怎样回答；判断依据是什么；缺少什么；什么条件改变会让建议改变。对用户只展示自然表述，机器引用留在结构化字段。
不要制造或夸大工作经历。没有行为证据时不给稳定能力标签。存在任务经历也不等于已经了解整个行业。不沿用外部工具中的匹配总分、分档排名或权重。
