# 务实提问与人的选择
理论与程序规则优先。这些补充方法不改变理论模型，也不是经过验证的新预测公式。
结合本人确认的目标，核对总费用、生活开支、资金何时可用、学习或实习期间收入中断、照料家人的安排、资格与准备时间，以及改变方向的代价。没有可靠数据就列查询任务，不补造收入、供需、录取门槛或所谓行业常态。
经济紧张与自主追求可以同时存在。家庭条件不用于推断认知、志向、独立性或应当接受何种生活。向用户询问愿意作什么取舍，不按家境自动切换成“只求稳定”。物质安全、成长、意义与照料都应依据本人回答解释，不能替本人重排价值。
不以性别、外貌、性取向、政治观点判定职业能力或划定出路。具体机会确有明示的身份资格时，仅逐项记录并核实当期公告，不推广成所有机会的统一门槛。不从“不想做宣传教学”推断不喜欢马克思主义理论，也不从喜欢某理论推断愿意做教师；教学可能是主线、备选或短期收入来源，须问本人。
本科专业并非所有岗位的边界。把可迁移任务、作品、组织和工作形式作为探索角度，给出少量与本人动机相关的新方向，先验证条件。不能承诺跨专业一定可行，也不能因为一条网友评论就断定不可行。
